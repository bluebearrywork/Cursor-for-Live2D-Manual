# Cursor for Live2D Manual

A structured, responsive user manual for **Cursor for Live2D**, focused on Live2D modellers.

## Contents

- Model importing and settings migration
- Scale, physics gain, and anchor configuration
- Keyboard/mouse expression bindings
- Application shortcuts
- Interactive cursor model workflow
- Pre-delivery checklist

## Local preview

This is a dependency-free static site. Open `index.html` directly, or serve the repository with any static HTTP server.

Use the language switcher in the top navigation, or open a language directly:

- Simplified Chinese: `index.html?lang=zh-CN`
- English: `index.html?lang=en`
- Japanese: `index.html?lang=ja`

## Deployment

The site is compatible with GitHub Pages and can be deployed directly from the repository root.

## Source

The content and screenshots were reorganized from the original Cursor for Live2D modeller manual. The source document is intentionally excluded from this repository.
